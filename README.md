# Hashim Girls Hostel

Professional website for **Hashim Girls Hostel** in Upper Chattar, Muzaffarabad, Azad Kashmir.

## Features

- Call and WhatsApp booking CTAs (`0346 8414184`)
- Email: `HGH.MZD@GMAIL.COM`
- Three-time meals, Wi‑Fi, in-house shop, secure gated premises
- Pricing: ₨15,000/month, ₨3,000 admission, no security deposit
- Real Google Maps photo gallery and embedded map
- Reviews section
- Mobile sticky Call / WhatsApp bar

## Run locally

```bash
npm install
npm run dev -- -p 43123
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Customize

Edit hostel details in `src/lib/hostel.ts` (name, address, phone, email, maps links, gallery, reviews).
